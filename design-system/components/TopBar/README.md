# TopBar

Barra superior de la web app: título/migas, búsqueda y acciones.

## Cuándo usarlo
Encabezado persistente de apps web.

## Variantes y estados
`leading`, `children` (buscador), `actions`.

## Móvil y otras plataformas
En móvil usa AppBar.

## Accesibilidad
`header`.

## Evita
—

## Props (React)

```ts
{ title?: ReactNode; leading?: ReactNode; actions?: ReactNode; children? }
```
