# EmptyState

Estado vacío con ilustración de marca (esquina firma), título esperanzador y acción.

## Cuándo usarlo
Listas sin datos, búsquedas sin resultados, primera vez.

## Variantes y estados
`icon`, `action`.

## Móvil y otras plataformas
Centrado verticalmente en el área de contenido.

## Accesibilidad
Título como h3.

## Evita
Nunca «No hay datos». Di qué pasará y cómo empezar.

## Props (React)

```ts
{ icon?: Icon; title: ReactNode; description?: ReactNode; action?: ReactNode }
```
