# DeviceFrame

Marco de teléfono (390×844) para documentar y prototipar pantallas móviles.

## Cuándo usarlo
Mockups, demos y presentaciones de la app móvil.

## Variantes y estados
`statusTone="brand"` para pantallas con cabecera azul. Usa `DeviceBody` para el área con scroll.
