# SearchField

Buscador en píldora con lupa.

## Cuándo usarlo
Filtrar listas y tablas en vivo.

## Variantes y estados
—

## Móvil y otras plataformas
iOS: UISearchBar / .searchable. Android: SearchBar.

## Accesibilidad
`type="search"`, `aria-label`.

## Evita
No pidas «Enter» si el filtro puede ser inmediato.

## Props (React)

```ts
{ placeholder?: string; value?: string; onChange?: (v) => void; label?: string }
```
