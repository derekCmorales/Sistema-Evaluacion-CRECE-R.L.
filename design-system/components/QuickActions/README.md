# QuickActions

Grilla de accesos rápidos con ícono duotono.

## Cuándo usarlo
Acciones frecuentes en inicio: pagar, transferir, ahorrar, solicitar.

## Variantes y estados
`columns`; ítem `accent` destacado.

## Móvil y otras plataformas
4 columnas en teléfono; íconos 56px.

## Accesibilidad
Texto visible bajo cada ícono.

## Evita
Máx. 8 acciones.

## Props (React)

```ts
{ items: { label, icon, accent?, onClick? }[]; columns?: number }
```
