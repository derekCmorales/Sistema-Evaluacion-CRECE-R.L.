# Overline

Antetítulo en mayúsculas espaciadas; con regla naranja opcional.

## Cuándo usarlo
Encima de títulos de página o sección para dar contexto («COOPERATIVA CRECE GUATEMALA», «PASO 2 DE 3»).

## Variantes y estados
`rule` añade la regla naranja de 24×2px (gesto de marca).

## Móvil y otras plataformas
Mismo estilo `overline` (11pt/sp, 700, tracking 0.14em).

## Accesibilidad
Es texto, no encabezado: no uses un h* solo para el overline.

## Evita
Una por bloque. Nunca como texto largo.

## Props (React)

```ts
{ children: ReactNode; rule?: boolean; as?: string }
```
