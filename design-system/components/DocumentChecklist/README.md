# DocumentChecklist

Lista de documentos requeridos con estado y acción de subir.

## Cuándo usarlo
Expediente de crédito, apertura de cuenta.

## Variantes y estados
Documento listo (verde) o pendiente (Subir).

## Móvil y otras plataformas
«Subir» abre cámara/archivos.

## Accesibilidad
Estado en texto.

## Evita
Explica por qué se pide cada documento.

## Props (React)

```ts
{ items: { key?, title, file? }[]; onUpload?: (item) => void }
```
