# Spinner

Indicador circular de carga para acciones puntuales.

## Cuándo usarlo
Dentro de botones o cargas breves de un bloque pequeño.

## Variantes y estados
`size`.

## Móvil y otras plataformas
iOS ProgressView, Android CircularProgressIndicator.

## Accesibilidad
`role="status"` con label.

## Evita
Para contenido estructurado usa Skeleton.

## Props (React)

```ts
{ size?: number; label?: string }
```
