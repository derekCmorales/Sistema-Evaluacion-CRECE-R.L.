# Divider

Separador horizontal, opcionalmente con texto.

## Cuándo usarlo
Separar grupos; «o continúa con».

## Variantes y estados
`label`.

## Móvil y otras plataformas
Hairline 1px.

## Accesibilidad
`role="separator"`.

## Evita
Prefiere espacio antes que líneas.

## Props (React)

```ts
{ label?: string }
```
