# Platforms

Exportaciones de los tokens para cada plataforma, generadas desde `design-system/src/tokens.mjs`:

- `crece-tokens.css` — variables CSS, temas claro/oscuro, @font-face y clases tipográficas (web, sitios, landings).
- `tailwind.preset.js` — preset de Tailwind sobre las variables CSS.
- `crece-theme.native.js` — React Native / Expo.
- `crece_theme.dart` — Flutter (ThemeData claro y oscuro).
- `CreceTheme.swift` — SwiftUI (colores dinámicos, fuentes, espacios).
- `tokens.dtcg.json` — W3C Design Tokens para Figma (Tokens Studio), Style Dictionary y Android.

Detalle y equivalencias de componentes en la sección Plataformas.
