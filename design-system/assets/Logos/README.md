# Logos

Archivos oficiales de CRECE Guatemala R.L., copiados del kit de marca (reescalados a 1600px de ancho, PNG con transparencia).

- `crece-horizontal-color.png` — versión principal: símbolo azul/naranja, texto azul. Header, pie, sidebar, documentos. Sobre `page`, `surface`, `soft`.
- `crece-horizontal-white.png` — tinta blanca. Modo oscuro, sobre `crece-blue` o fotografía.
- `crece-horizontal-black.png` — tinta negra (#000). Impresión a una tinta, fax, sellos.
- `crece-horizontal-color-dark-text.png` — variante permitida con «GUATEMALA R.L.» en tono oscuro.
- `crece-vertical-*` — mismas variantes apiladas para formatos cuadrados, avatares, favicon (el sitio usa la vertical como ícono), portadas y merchandising.

Área de reserva: 10% del tamaño del logo por lado. No rotar, distorsionar, cambiar proporciones ni reordenar símbolo y texto.
