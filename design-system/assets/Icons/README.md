# Icons

147 SVG de Phosphor Icons (MIT) a 32px con tinta `crece-blue` (#034381): los 137 íconos curados del sistema en peso regular, más variantes `-duotone` y `-fill` de los más usados. Para diseño, presentaciones y piezas estáticas. En código usa `Crece.Icons.<Nombre>` o el paquete Phosphor de tu plataforma (heredan `currentColor`). Vocabulario y pesos en la sección Iconografía.
